# BALANCEO---CARGAS---NGNIX---SERVER
Proyecto final del curo "SISTEMAS OPERATIVOS": Este proyecto incluye la configuración de una infraestructura containerizada con un servidor Nginx como proxy inverso, múltiples instancias de backend, y la integración de un sistema de monitoreo como Prometheus y Grafana, junto con sus exportadores (Nginx Prometheus Exporter y cAdvisor).
